@property

Register custom properties with a type. Now the browser can interpolate them. Animate gradients, counters, colors — without a single line of JavaScript.

/* Register the property first — tell browser what TYPE it is */ @property --gradient-angle { syntax: '<angle>'; /* can be deg, rad, turn */ inherits: false; initial-value: 0deg; } /* Now transition WORKS because browser knows how to interpolate <angle> */ .box { background: conic-gradient(from var(--gradient-angle), red, blue); transition: --gradient-angle 1s ease; /* ← this line now works! */ } .box:hover { --gradient-angle: 360deg; }
