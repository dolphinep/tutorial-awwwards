EXERCISE

  1. Animated text reveal mask: Create a .reveal element. Use mask-image with a gradient that animates from all-transparent to all-black on page load via @keyframes
  2. Image-in-text: Add a full-width element with a real background-image URL. Apply background-clip: text to make a big headline "filled" with the image
  3. Grain overlay: Use mix-blend-mode: overlay on a pseudo-element with an SVG noise texture to add film grain to any section
  4. Scroll-driven mask: Use JS to update a --scroll CSS variable on scroll, then use it in a mask gradient to reveal an element as you scroll past it
