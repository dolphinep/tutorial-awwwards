CLIP-PATH

Cut elements into any shape. The browser clips everything outside. No Photoshop, no SVG files — pure CSS.

BREAK THE
RECTANGLE

clip-path: polygon() lets you escape the box model. This diagonal cut is three coordinates: the bottom-right is pulled up, bottom-left stays.

/* DIAGONAL SECTION — most common Awwwards technique */ .section { clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%); /* top-left top-right bottom-right bottom-left */ } /* Animate any clip-path with transition */ .box { clip-path: circle(40% at 50% 50%); transition: clip-path 0.5s cubic-bezier(0.16, 1, 0.3, 1); } .box:hover { clip-path: circle(70% at 50% 50%); } /* RULE: both shapes must have the same number of points to animate */

Technique 2 — shape-outside (text wraps around a shape)

/* ONLY works on floated elements */ .triangle { float: left; width: 220px; height: 220px; shape-outside: polygon(50% 0%, 100% 100%, 0% 100%); clip-path: polygon(50% 0%, 100% 100%, 0% 100%); } /* Text flows around the shape-outside boundary */

Typography and geometry have always been in conversation. When text wraps around a shape, the layout breathes differently — each line finds its own length, guided by the invisible boundary of the form beside it. This is what print designers have known for decades: the white space is not empty. It is shaped. It carries meaning. The triangle commands the eye, and the words orbit around it like planets caught in a field of gravity. Only CSS and a float make this possible. No JavaScript. No image editors. Just coordinates and the browser's rendering engine doing what it was built to do.
