Technique 2 — Overlapping grid items

/* Items can share cells — use z-index to layer */ .bg-block { grid-column: 1 / 9; grid-row: 1 / 3; } .red-block { grid-column: 6 / 13; grid-row: 1 / 2; z-index: 1; } .text-layer { grid-column: 2 / 8; grid-row: 1 / 2; z-index: 2; } /* text-layer overlaps both bg AND red — intentional depth */

Technique 3 — Subgrid (baselines align across cards)

.parent { display: grid; grid-template-columns: repeat(3, 1fr); } .card { display: grid; grid-row: span 3; grid-template-rows: subgrid; /* aligns to PARENT tracks */ } /* Now .card-tag, .card-title, .card-body all align across siblings */ /* even when content lengths differ — impossible without subgrid */
