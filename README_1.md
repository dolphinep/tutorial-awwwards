# Phase 1 — Advanced CSS

No Tailwind. No frameworks. Raw CSS only. This is how you understand what tools do for you.

## Structure

```
phase-1/
├── 01-css-variables/     Task 1: Design tokens, scoped vars, JS ↔ CSS bridge
├── 02-css-grid/          Task 2: Named areas, subgrid, overlapping items
├── 03-clip-path/         Task 3: clip-path shapes, shape-outside, animations
├── 04-css-property/      Task 4: @property, animated gradients, CSS counters
├── 05-masks-blend/       Task 5: mask-image, mix-blend-mode, duotone effects
└── 06-mini-project/      Task 6: Everything combined — editorial layout
```

## How to use

Open each `index.html` directly in your browser (no server needed).
Read the comments in the `<style>` block — they explain the WHY, not just the what.
Do the exercise at the bottom of each file before moving on.

## Order of learning

Go in order: 01 → 02 → 03 → 04 → 05 → 06.
Task 06 is the synthesis — build `my-version.html` from scratch without looking at the source.

## Key mindset

> "You can only break rules you understand."

Every technique here is something Tailwind hides from you. After this phase, you'll see how
Awwwards sites are built at the CSS level — not as magic, but as intentional code.
